नौकरी वाले करणी माता- श्री खटुन्दरा राय — वेबसाइट फाइलें

इस फोल्डर में:
- index.html : पूरी वेबसाइट का सोर्स कोड
- images/ : आपके भेजे हुए मूल मंदिर/पूजा फोटो

GitHub पर डालने का तरीका (मोबाइल से):
1. GitHub में अपना repository खोलें।
2. Add file > Upload files चुनें।
3. इस ZIP को पहले अपने फोन में extract/unzip करें।
4. index.html और images फोल्डर को repository में अपलोड करें। ध्यान रहे कि images फोल्डर के अंदर तीनों JPG फाइलें भी अपलोड हों।
5. Commit changes दबाएँ।
6. Repository > Settings > Pages में जाएँ।
7. Build and deployment में Deploy from a branch चुनें, Branch: main और folder: /(root) चुनें, फिर Save दबाएँ।
8. कुछ मिनट बाद GitHub Pages में दिखने वाला वेबसाइट लिंक खोलें।

नोट:
- वेबसाइट में AI से बनाई गई कोई नई तस्वीर शामिल नहीं है; केवल उपयोगकर्ता द्वारा भेजे गए मूल फोटो लगाए गए हैं।
- अगर GitHub पर index.html पहले से है, तो नई फाइलें अपलोड करने से पहले उसका backup रख लें।
